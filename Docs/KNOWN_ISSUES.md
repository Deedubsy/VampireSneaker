# VESPERTINE — Known Issues, Limitations, Technical Debt

## Placeholder assets requiring professional replacement
| Asset | Current | Replace with |
|---|---|---|
| Characters | Primitive-composed low-poly figures, no skeletal animation (procedural bob/lean) | Rigged stylised models + animation sets (walk, run, climb, feed, die, carry) |
| Environment | Greedy-merged boxes with palette materials | Modular gothic kit (brick, slate, iron) |
| Audio | Runtime-synthesised SFX/ambience (only amb_night, amb_drip, amb_water, amb_rain exist) | Recorded/designed SFX, score |
| Music | `music=` header keys (`drowned`, `lantern`, `docks`, `cathedral`, `gasworks`, `masque`, `bridges`, `hunt`) have no clips yet; silence apart from ambience and stings | Composed score per act |
| Fonts | Open-licensed Google Fonts (OFL) | Keep or license a display face |
| Icons | Unicode/geometric glyphs | Painted ability icons |
| VO | None (subtitled barks) | Voice cast |
